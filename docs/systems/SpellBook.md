### C_SpellBook.FindSpellBookSlotForSpell

`C_SpellBook.FindSpellBookSlotForSpell(spellIdentifier: SpellIdentifier, includeHidden: bool = False, includeFlyouts: bool = True, includeFutureSpells: bool = False, includeOffSpec: bool = False) → spellBookItemSlotIndex: luaIndex, spellBookItemSpellBank: SpellBookSpellBank`

- Status: ✅ verified (function)
- Blizzard: If found, returns the first slot position of a SpellBookItem matching the specified spell and criteria
- `includeHidden`: If true, search includes SpellBookItems that are hidden from the SpellBook UI (ex: spells that have been replaced, are also in a Flyout, etc)
- `includeFlyouts`: If true, search includes Flyout SpellBookItems containing the specified spell
- `includeFutureSpells`: If true, search includes SpellBookItems for spells that have not yet been learned
- `includeOffSpec`: If true, search includes SpellBookItems belonging to non-active specializations; If spell is in active and inactive spec, the active spec slot will always be returned
- may return nothing (Blizzard's docs; not checked in game)
- secret arguments: AllowedWhenUntainted (Blizzard's docs; not checked in game)
- Source: client docs `SpellBookDocumentation.lua`
